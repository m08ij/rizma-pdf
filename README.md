# رزمة PDF

موقع بسيط يحوّل صور دفاترك الجامعية وتلاخيصك وسلايداتك إلى ملف PDF واحد مرتب. كل المعالجة تتم داخل المتصفح، ولا تُرفع الصور إلى أي خادم.

## الميزات

- **ترتيب تلقائي حسب رقم الصفحة:** يقرأ الرقم المكتوب أعلى الصفحة أو أسفلها ويرتب الصور. الصفحات التي لم يُقرأ رقمها تُعلَّم بالأصفر لتكتب رقمها يدوياً.
- **أربعة قوالب جاهزة:** دفتر جامعي، تلاخيص، سلايدات، سلايدات للطباعة.
- **ترتيب يدوي:** بسحب البطاقات، أو حسب اسم الملف، أو حسب وقت التصوير.
- **محرر لكل صورة:** تدوير، قص للحواف، سطوع وتباين، وفلاتر منها المسح الضوئي والأبيض والأسود.
- **إعدادات الصفحة:**
  - مقاسات A4 وA5 وB5 وLetter و16:9، أو على مقاس الصورة.
  - من صورة إلى ٦ صور في الصفحة.
  - الهوامش والإطار ونقشة الورق.
- **إضافات للملف:** ترويسة، وترقيم للصفحات، وعلامة مائية، وصفحة غلاف.
- **معاينة مباشرة** لكل صفحة قبل التنزيل.

## الاستخدام

افتح `index.html` في المتصفح، أو استخدم نسخة GitHub Pages.

## ملاحظات

- قراءة أرقام الصفحات تعمل بأفضل شكل مع الأرقام اللاتينية (1، 2، 3). الأرقام العربية المشرقية (١، ٢، ٣) يمكن كتابتها يدوياً.
- صور HEIC من الآيفون يجب تحويلها إلى JPG أولاً.

مبني بـ [jsPDF](https://github.com/parallax/jsPDF) و [SortableJS](https://github.com/SortableJS/Sortable) و [Tesseract.js](https://github.com/naptha/tesseract.js).
