# رزمة PDF

موقع يحوّل صور دفاترك الجامعية وتلاخيصك وسلايداتك إلى ملف PDF واحد مرتب. كل المعالجة تتم داخل المتصفح، ولا تُرفع الصور إلى أي خادم.

**الموقع:** https://m08ij.github.io/rizma-pdf/

## الميزات

- **قص الورقة تلقائياً:** يكتشف حواف الورقة في الصورة، ويزيل الطاولة، ويعدّل الميلان. ويمكنك تحريك الزوايا الأربع بيدك من المحرر.
- **ترتيب تلقائي حسب رقم الصفحة:**
  - يبحث عن الرقم في زوايا الصفحة وأعلاها وأسفلها، ويقرأ كل منطقة مكبّرة وبأكثر من إعداد تباين.
  - يقرأ الأرقام اللاتينية (12) والعربية المشرقية (١٢)، بما فيها الصفر (٢٠، ١٠٠).
  - **دفاتر بخط اليد:** يجد الرقم المحاط بدائرة أعلى الصفحة، أو عنواناً مثل «lecture 25»، ويقرأ الأرقام المكتوبة باليد بشبكة عصبية صغيرة تعمل داخل المتصفح. صفحة العنوان توضع أولاً بين الصفحات التي تحمل الرقم نفسه.
  - إذا تكرر الرقم في أكثر من صفحة (رقم المحاضرة مثلاً) يُعامل التكرار كأمر طبيعي.
  - يقارن الأرقام بين الصفحات ليكتشف المكرر والشاذ، ويعلّم الأرقام غير المؤكدة بالبرتقالي.
  - يرسم مربعاً على الصورة في المكان الذي قرأ منه الرقم.
- **تحديد عدة صور** لتدويرها أو حذفها أو نقلها معاً، مع **تراجع وإعادة** (Ctrl+Z و Ctrl+Y).
- **ملف قابل للبحث:** يضيف طبقة نص مخفية بالعربية والإنجليزية، فتبحث عن أي كلمة داخل الـ PDF.
- **أربعة قوالب جاهزة:** دفتر جامعي، تلاخيص، سلايدات، سلايدات للطباعة.
- **محرر لكل صورة:** زوايا الورقة، وتدوير، وقص للحواف، وسطوع وتباين، وفلاتر منها المسح الضوئي.
- **إعدادات الصفحة:** مقاسات A4 وA5 وB5 وLetter و16:9، ومن صورة إلى ٦ صور في الصفحة، وهوامش وإطار ونقشة ورق.
- **إضافات للملف:** ترويسة، وترقيم، وعلامة مائية، وصفحة غلاف.
- **وضع فاتح ووضع داكن.**

## الملفات

| الملف | الوظيفة |
| --- | --- |
| `index.html` | هيكل الصفحة |
| `assets/style.css` | التصميم (فاتح: استوديو، داكن: ليلي) |
| `assets/app.js` | منطق الموقع: الصور، الترتيب، التراجع، المعاينة، التصدير |
| `assets/scan.js` | اكتشاف الورقة وتعديل المنظور |
| `assets/ocr.js` | قراءة أرقام الصفحات المطبوعة وطبقة النص |
| `assets/hand.js` | قراءة أرقام الصفحات المكتوبة بخط اليد |
| `assets/hand-model.js` | أوزان الشبكة العصبية لقراءة الأرقام (MNIST) |

## ملاحظات

- قراءة الأرقام المكتوبة بخط اليد أصعب من المطبوعة، فراجع الأرقام البرتقالية والصفراء قبل التنزيل.
- قارئ الأرقام والنصوص يُحمَّل عند أول استخدام، ويحتاج اتصالاً بالإنترنت تلك المرة.
- صور HEIC من الآيفون يجب تحويلها إلى JPG أولاً.

مبني بـ [jsPDF](https://github.com/parallax/jsPDF) و [pdf-lib](https://github.com/Hopding/pdf-lib) و [SortableJS](https://github.com/SortableJS/Sortable) و [Tesseract.js](https://github.com/naptha/tesseract.js).
